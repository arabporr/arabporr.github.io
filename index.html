Forecasting return distributions across interpretable stochastic regimes, with a separate risk-neutral component for derivatives pricing.

Low-dimensional approximations of the conditional law of Volterra processes: a non-positive curvature approach

Luca Galimberti, Reza Arabpour, John Armstrong, Anastasis Kratsios, Giulia Livieri

Using geometric structure and hypernetworks to approximate the evolving distributions of financial processes with memory.

Read paper ↗
Abstract +
Volterra processes capture memory effects that make financial dynamics difficult to model. This work combines dimension reduction onto a statistical manifold of non-positive curvature with a geometry-aware learning model. A hypernetwork updates the model over time to represent changing conditional distributions.
Geometric learning
03 /
ICML 2025 · ES-FoMo Workshop2025

LoRA Fine-Tuning Without GPUs: A CPU-Efficient Meta-Generation Framework for LLMs

Reza Arabpour, Haitz Sáez de Ocáriz Borde, Anastasis Kratsios

Generating task-specific language-model adapters on a CPU by combining a bank of pretrained LoRAs.

Read paper ↗Code ↗
Abstract +
The framework uses relationships between datasets to construct new adapters from existing ones, without fresh gradient-based adapter training. Adapter generation runs on a CPU; the large-scale model inference and evaluation experiments use GPU resources. The resulting adapters improve on the base model, while GPU-trained adapters remain stronger.
Efficient adaptation
